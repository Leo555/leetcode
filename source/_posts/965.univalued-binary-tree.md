## [单值二叉树](https://leetcode.cn/problems/univalued-binary-tree/)

如果二叉树中所有节点值都相同，返回 true。

<!-- more -->

示例 1:

> 输入：[1,1,1,1,1,null,1]
> 输出：true

示例 2:

> 输入：[2,2,2,2,2,null,3]
> 输出：false

提示:

- 树中节点数在 1 到 100 之间
- -100 <= node.val <= 100

## 解析

递归检查所有节点值是否与根节点相同。

```javascript
var isUnivalTree = function (root) {
  const val = root.val;

  const dfs = (node) => {
    if (!node) return true;
    if (node.val !== val) return false;
    return dfs(node.left) && dfs(node.right);
  };

  return dfs(root);
};
```

时间复杂度 O(N)，空间复杂度 O(H)。
